# 版本变更

本文件仅记录对公开使用者和贡献者有意义的变化。

## [2.0.1] - 2026-09-01

### 新增

- 支持备份任意博主的微博：主页直接输入昵称搜索（带 V 的排前面，显示认证说明、粉丝数），或粘贴主页链接/分享文本；选中后选择保存位置即可建立微博书，之后可持续增量更新，与本人微博书同一套档案、互动 HTML 与 PDF 能力。第一版不含评论与关注资料。

### 修复

- 修复旧档案（年-月媒体目录迁移前创建）中转发微博与引用卡片图片仍指向旧平铺路径、导致 PDF 生成报「本地图片加载失败」的问题；打开档案时自动补写内嵌路径。
- 备份他人微博时，若对方时间轴混入广告/推广卡，该条目跳过并计入不可用，不再导致整轮备份中断丢失进度。
- 备份中断后的恢复卡片能正确区分本人与他人档案：他人任务显示「@昵称 的微博书」，不再一律显示「本人微博书」。
- 首次建立/重建中途意外退出（崩溃、断电、强杀）不再丢失已抓进度：临时归档保留，「继续任务」从中断点续跑；旧版本造成的进度丢失记录现在可以正常放弃，并会明确提示重新开始备份。
- 修复抓取一结束界面就提前显示「微博书归档已完成」的问题：生成三种格式与离线数据期间（大档案的 PDF 可能要几分钟）界面会显示「正在生成」，全部文件就绪后才显示完成，计时也不再显示 0.0 秒。
- 修复抓取中途六步进度条的已完成步骤被意外清空的问题：「发现分页」「处理评论」阶段现在正确归入「抓取微博」步骤。
- 删除 Windows 版顶部「完整体验请使用 Mac 版」提示条。
- 关注资料更新时，平台未返回的关注博主不再导致整体失败，单独标记为「状态未确认」，关系和数据保留；完整运行后仍缺失才进入「不再关注」。

### 变更

- 增量更新的旧微博复查窗口从最近 50 条收窄为最近 5 条，减少每次备份的重复抓取开销。
- 选择备份文件夹后自动在其中创建「昵称_UID」子文件夹存放微博书，不再与文件夹内其它文件混放；再次选择同一个父目录会自动识别并续上已有微博书。

## [2.0.0] - 2026-08-24

> Mac 主线及正式发布前的后续开发固定使用 `2.0.0`。

### 修复

- 修复 frozen Windows `console=False` 时 `tqdm` 在 `__init__` 阶段写已关闭的标准输出流导致的 `ValueError: I/O operation on closed file` 崩溃；个人档案备份任务在下载媒体阶段不再中断。无可用控制台流时使用 disabled tqdm，同时保留结构化进度事件。
- 修复开发版 `.app` 从 Finder 启动后回落到日常个人 profile 的问题。源码开发态与 `WeishushuDev.app` 使用 `.weibo_book_cookies_dev` 和 `WeishushuDev` 运行目录；日常个人版继续使用 `.weibo_book_cookies` 和 `Weishushu` 运行目录。
- 修复内置浏览器登录监视器只读取本机 Cookie 文件、不持续导出浏览器最新 Cookie 的问题。顶部登录入口和右上角浏览器入口现在复用同一会话监视器，并先同步浏览器状态再刷新主界面。

### 新增

- 新增 Apple Silicon macOS 桌面主线，使用系统 WKWebView 提供同窗微博浏览区。
- 新增可携带的本地档案，支持首次建档、增量更新、重建、固定文件发布和媒体相对路径。
- 新增手机微博式互动 HTML，支持媒体网格、引用卡片、灯箱、评论详情和实况照片配对播放。
- 新增 JSON 和 CSV 结构化导出。

### 变更

- 桌面端主登录按钮统一为“打开内置浏览器登录”；内置浏览器登录成功后自动校验并写入同一个本机 Cookie 文件，“从 Chrome 导入”保留为备用入口。
- Windows 独立内置浏览器窗口支持导出登录 Cookie、导航后自动同步和手动“同步登录”；Chrome 导入后台任务与扫码登录一样经线程池执行。
- Windows frozen 的 Playwright Chromium 统一放到 `_internal/ms-playwright/chromium-*`，并兼容旧 `_internal/chromium-*` 根布局。
- 将 Codex 和其他开发代理的项目入口统一为 `AGENTS.md`，不再生成或维护 `CLAUDE.md`。
- 将互动 HTML 与 PDF 打印模板分离，Markdown 保持独立生成链路。
- 实况照片保存同一基础编号的静态图和配对视频，不自动导入 Apple Photos。
- 加强登录数据权限、请求限速、资产代理跳转校验、任务取消和封装检查。
- 明确源代码许可与官方构建产物分发政策的边界。

## [1.1.6]

### 新增

- 新增基于 WeasyPrint 的 PDF 生成链路和中文字体支持。
- 新增历史档案列表、搜索和运行时清理辅助脚本。

### 修复

- 修复 Windows GBK 终端中某些日志字符导致的编码异常。
- 修复部分封装资源、版本号和安装脚本不一致问题。

## 始终不提供的功能

本项目不提供评论发布、点赞自动化、关注自动化、转发自动化、多账号池、代理池、Cookie 池、验证码绕过、OAuth 商业用途或跨设备同步登录。
