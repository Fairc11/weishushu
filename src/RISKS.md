# ⚠️ RISKS — 微书薯风险策略文档（v1.2.0 起强制）

> **🚨 必读** — 本项目所有 AI（Codex / OpenCode / OpenClaw / 任何 LLM 代理）在开始任何任务**前**都必须读这份文档。**不读 = 必踩坑**。

## 0. 一句话定性

微书薯 = **桌面端单进程单设备单 cookie 抓本人可见数据**。**完全不是**"商业全量采集器" / "账号池/代理池" / "互动自动化" / "评论发布"。

## 1. 风险分类（8 大类 — 穷尽）

### 1.1 🟡 站点 robots.txt 风险
- weibo.com/robots.txt 名义整站 Disallow，但仅对白名单蜘蛛开放
- **执行** = 法律声明层面，不构成 WAF 拦截
- **本项目风险** = 🟡 中，**不是直接风险**

### 1.2 🟢 开放平台 OAuth 条款
- 开放平台 OAuth 限 100 次/用户/天 + 15,000 次/IP/小时
- **本项目不走 OAuth 路线**（用 cookie 走 m.weibo.cn），因此 OAuth 配额不适用；这不代表抓取行为没有平台协议风险。

### 1.3 🟡 用户协议风险
- 《微博服务使用协议》1.3.2、1.4 和 4.5 明确限制未经书面许可的程序抓取、非正常浏览和自动化抓取数据。
- **本项目 = 非商业、熟人私域、本地单账号只读**，只用于限制产品范围和降低扩大使用带来的风险，不构成微博书面许可，也不能表述为“零风险”。
- 项目不得向用户承诺账号绝对安全、不会受限或不会被处理。

### 1.4 🟡 单 IP 频率触发风控
- 微博 m.weibo.cn 滑块验证码（432 状态）= 临时拦截
- **本项目 = 单设备单 IP 单进程**，但现有标准抓取不能据此称为低频。
- 无法根据一次公开案例推导任何账号都不会受到进一步处理。
- 2026-07-17 本机安装的 `crawl4weibo 0.5.2` 在无代理时遇到 `432` 只会随机等待 4～7 秒后重试，达到重试上限后抛出 `NetworkError`，并没有 1～2 小时指数退避。
- **处理策略**：遇到 `432`、验证页面或登录失效时暂停任务并提示用户，不自动绕过，不连续短间隔重试。

### 1.5 🔴 **多 cookie/多 IP/多设备并发**（v1.2.0 关键风险）
- 同一账号 cookie 在多 IP 或多设备间切换可能触发登录失效、重新验证或账号功能限制。
- "软封" 强制重新扫码
- **本项目 v1.2.0 边界**：
  - ✅ 单设备 1 cookie 1 进程 1 IP = 🟢 低
  - ❌ **多账号轮询** = 🔴 高（不做）
  - ❌ **多 IP 切换** = 🔴 高（不做）
  - ❌ **多设备同时登录** = 🔴 高（不做）
- **v1.2.0 内置浏览器禁止的：cookie 池 / 账号池 / 代理池**

### 1.6 🟡 账号处理结果不可预测
- 公开项目未出现某类 issue，不能证明账号不会受到警告、验证、功能限制、暂停服务或注销等处理。
- 《微博服务使用协议》8.5 列明警告、禁言、限制功能、暂停服务和注销账号等措施。
- 本项目只能降低请求密度、限制功能和在异常时暂停，不能量化或消除账号风险。

### 1.7 🔴 商业分发/陌生用户场景（永远不做）
- 陌生用户拿本项目抓别人账号 = 行为不可控 = 高风险
- ❌ 任何 "SaaS 化" / "账号代抓服务" = 不做
- ❌ 任何 "打包账号包分发" = 不做

### 1.8 🔴 **绝对不做清单**（10 类，违反任何一条 = 拒改）
1. ❌ **评论发布**（反爬/可能封号/产品定位是只读）
2. ❌ **点赞自动化**（高封号风险）
3. ❌ **关注自动化**（高封号风险）
4. ❌ **转发自动化**（高封号风险）
5. ❌ **多账号池**（个人+商业均封号）
6. ❌ **代理池/IP 轮询**（隐藏身份 = 主动违规）
7. ❌ **Cookie 池/账号包**（明文存储 = 隐私灾难）
8. ❌ **验证码绕过**（如打码平台）= 主动违规
9. ❌ **微博 OAuth appkey 商业用途**（未经审核发微博 = 平台规则）
10. ❌ **跨设备/多 IP 同步登录**（账号池前置）

## 2. v1.2.0 实施边界（基于 RISKS §1.5）

### 2.1 ✅ 允许的
- ✅ **v1.2.0 内置浏览器** = 单设备 1 cookie 1 进程
- ✅ **cookie 注入到内置浏览器** = 用户自家 cookie 注入自家浏览器
- ✅ **m.weibo.cn 浏览** = 用户手动浏览
- ✅ **复制 URL 到左边** = 触发提取
- ✅ **本人 + 公开账号**抓公开内容
- ✅ **本人收藏 / 评论**抓（用户在本人微博页可见的）

### 2.2 ❌ 禁止的
- ❌ **多账号切换**（v1.2.0 不实现）
- ❌ **跨设备 cookie 同步**
- ❌ **代理池 / IP 轮询**
- ❌ **未经用户明确启动的后台自动抓取**；用户主动启动后最小化继续属于同一任务，不得演变为定时自动联网
- ❌ **频率超过爬 1 个用户/分**（限速 3/min 已写）
- ❌ **评论 / 点赞 / 关注 / 转发自动化**

## 3. 安全编码铁律（AI 必读）

### 3.1 cookie 存储
- ✅ **本地文件** `~/.weibo_book_cookies`（S2 v1.1.1 已 icacls 收紧到当前用户）
- ❌ **永不上传** cookie 到任何云端
- ❌ **永不打印** cookie 到 log（用 `redact_cookies()`）
- ❌ **永不进 git**（`.gitignore` 已配）

### 3.2 日志输出
- ❌ **不输出** cookie 完整值（红 `***`）
- ❌ **不输出** 用户密码（扫码登录时已无密码流程）
- ✅ **输出** 任务 ID / 文件路径 / 数量 / 进度

### 3.3 错误处理
- ✅ **WeiboError(kind)** 分类抛（AUTH/NETWORK/RATE_LIMIT/NOT_FOUND/PARSE/UNKNOWN）
- ✅ **中英文错误关键字**（classify_error 含"超时/网络/断网"）
- ❌ **不抛 RuntimeError**（前端无法区分错误类型）
- ✅ **rate limit 触发自动等 60s 重试一次**（v1.1.1 S4）

### 3.4 用户教育
- ✅ **README 必加"风险声明"段**
- ✅ **CHANGELOG 必加"不做"段**
- ✅ **v1.2.0 内置浏览器弹"风险须知"首启模态**

## 5. 风险升级路径

| 触发 | 升级 | 谁 |
|------|------|---|
| 单用户 `432`、验证页面或登录失效 | 暂停任务，保存安全点，等待用户处理后手动恢复 | 项目自身实现 |
| 多 IP 触发"软封" | 强制重新扫码 | v1.2.0 cookie 失效 |
| 公开封号案例 | 立刻停服 + 出致歉公告 | 项目 owner |
| 微博律师函 | 立刻下架所有渠道 + 联系法律 | 项目 owner |
| 安全漏洞（cookie 泄漏） | 72h 内修复 + 通知所有用户 | 项目 owner + 开发者 |
